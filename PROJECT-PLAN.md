# ACRP-07 Project Plan — The Valuation Reading of the Qubit Delusion

## §1 Charter
ACRP-07 applies the adelic valuation kernel to the Qubit Delusion thesis (DOI 10.5281/zenodo.21254143). The K3 audit finding (ACRP-01, DOI 10.5281/zenodo.21727314) is that the Qubit Delusion paper has NO explicit kernel use. This paper answers: is the bridge between the Qubit Delusion's epistemic critique and the adelic valuation framework load-bearing — does the kernel constrain, sharpen, or bound the Qubit Delusion's claims — or is it aesthetic?

## §1.2 Core Question (HARD GATE)
**K3 audit finding:** "Qubit Delusion has NO explicit kernel use."

**Two possible verdicts:**
- **(a) Load-bearing:** The valuation kernel (valuation → tree boundary → Ostrowski → adeles) provides a novel bound or constraint on QEC overhead, qubit-count projections, or the epistemic critique that Archimedean methods miss.
- **(b) Aesthetic:** The kernel reframes existing QEC overhead claims (O(n²) physical qubits, 99% ancilla overhead) in valuation-theoretic language without changing the estimates. The bridge is descriptive, not load-bearing — which IS a publishable result.
